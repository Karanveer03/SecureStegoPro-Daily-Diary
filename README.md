## 📘 Project Overview

**SecureStegoPro** is a hybrid data protection project that combines the power of **Cryptography** and **Steganography** to securely transmit sensitive data.

### 🔐 Cryptography
- Uses **AES (Advanced Encryption Standard)** for secure data encryption.  
- Ensures confidentiality even if data is intercepted.

### 🖼️ Steganography
- Uses **Least Significant Bit (LSB)** technique to hide encrypted data inside images.  
- Maintains high visual quality of images (PSNR > 50 dB).  

### 🧩 Combined Workflow
1. Encrypt data using AES  
2. Embed encrypted data into an image  
3. Extract and decrypt when needed
